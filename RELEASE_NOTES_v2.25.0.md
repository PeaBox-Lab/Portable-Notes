# Portable Notes 2.25.0: Schedule Plan

This cumulative release converts open Markdown work into a deterministic daily execution plan.

## New
- `/api/task-schedule` with configurable 1-24 hour daily capacity
- Optional project filtering
- Due-date and priority aware task ordering
- Effort splitting across capacity-constrained days
- Projected plan finish date
- New Schedule Plan command

## Retained
All v2.24 and earlier note, search, knowledge, task/project/milestone, dependency, critical-path, risk, workload, capacity, burndown, forecast, history, attachment, export, template, daily-note and privacy functionality remains.
