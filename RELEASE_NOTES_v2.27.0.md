# Portable Notes 2.27.0: Baseline Health

This cumulative release adds project baseline-governance health while retaining every earlier capability.

## New
- `/api/task-baseline-health` with optional project filtering
- Baseline coverage percentage
- Tracked versus untracked task counts
- Slipped, ahead and on-baseline rollups
- Average slippage and overdue indicators
- Deterministic Green, Amber and Red project health state
- New Baseline Health command

## Retained
All v2.26 and earlier note, search, knowledge, task/project/milestone, dependency, critical-path, risk, workload, capacity, burndown, forecast, schedule, slippage, history, attachment, export, template, daily-note and privacy functionality remains.
