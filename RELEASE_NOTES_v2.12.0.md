# Portable Notes 2.26.0: Productivity Stats

A cumulative release adding lightweight productivity analytics derived from Markdown tasks.

## New
- `/api/task-stats` productivity endpoint
- Completion percentage and open/completed counts
- Overdue and due-today metrics
- Open-task distribution by priority
- Per-project completion/open rollups
- New Productivity Stats command

## Retained
All v2.11 and earlier notes, FTS search, knowledge tools, task intelligence, dashboard, calendar, board, focus view, weekly review, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault, and local-first privacy features.
