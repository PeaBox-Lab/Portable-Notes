# Portable Notes 2.21.0: Task Board

This cumulative release turns Markdown tasks into a lightweight Kanban-style workflow without introducing a second source of truth.

## New
- `/api/task-board` with Overdue, Today, Upcoming, No Due Date, and Done lanes
- Optional project filtering
- Priority-aware ordering within lanes
- Task Board command-palette action
- Board entries preserve source note, path, line, due date, priority, and project context

## Retained
All v2.8 and earlier notes, FTS search, saved searches, knowledge tools, task intelligence, project dashboard, calendar, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault and local-first privacy capabilities.
