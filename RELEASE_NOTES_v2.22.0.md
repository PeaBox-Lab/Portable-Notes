# Portable Notes 2.22.0: Capacity Planning

This cumulative release adds seven-day capacity planning on top of Markdown effort estimates.

## New
- `/api/task-capacity` with configurable weekly capacity, bounded to 1-168 hours
- Optional project filtering
- Seven-day estimated demand versus capacity
- Utilization percentage and remaining hours
- Available, Tight, and Overloaded status
- Unestimated and overdue work visibility
- New Capacity command

## Retained
All v2.21 and earlier notes, search, knowledge, task/project/milestone workflows, dependencies, critical path, risk radar, workload planning, history, attachments, export, templates, daily notes, custom vault and privacy functionality remains.
