# Portable Notes 2.26.0: Task Dependencies

This cumulative release adds lightweight task dependency tracking while preserving all earlier functionality.

## New
- Task identifiers via `taskid: ID` or `#task/ID`
- Dependencies via `depends: ID` or `#depends/ID`
- `/api/task-dependencies` with optional project filtering
- Ready, Blocked, and Unresolved classifications
- Missing-dependency diagnostics and waiting-on details
- New Task Dependencies command

## Retained
All v2.17 and earlier notes, search, knowledge tools, task intelligence, dashboards, calendar, board, focus, weekly review, productivity stats, project health/workspace/timeline, milestones and milestone board, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault and privacy features.
