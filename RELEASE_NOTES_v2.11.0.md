# Portable Notes 2.24.0: Weekly Review

A cumulative release adding a weekly planning/review workflow while preserving all earlier Portable Notes capabilities.

## New
- `/api/task-review` weekly review endpoint
- Summary for total, open, completed, overdue, next-7-day, and undated tasks
- Open-work rollup by project
- Detailed overdue and upcoming task lists
- New Weekly Review command-palette action

## Retained
All v2.10 and earlier Markdown notes, FTS search, knowledge tools, tasks, task dashboard, task calendar, task board, focus view, wiki links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault, and local-first privacy features.
