# Portable Notes 2.20.0: Project Workspace

This cumulative release adds a focused project workspace while preserving every earlier Portable Notes capability.

## New
- `/api/task-project?project=Name` focused project endpoint
- Project completion, open/done, overdue, high-priority and next-due metrics
- Source-note count for project work
- Risk-aware ordered project task list
- New Project Workspace command

## Retained
All v2.13 and earlier notes, FTS search, knowledge tools, task intelligence, dashboards, calendar, board, focus, weekly review, productivity stats, project health, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault and local-first privacy features.
