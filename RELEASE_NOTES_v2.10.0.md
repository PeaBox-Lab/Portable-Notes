# Portable Notes 2.15.0: Focus View

A cumulative release adding a prioritized short-horizon work view while retaining all earlier capabilities.

## New
- `/api/task-focus` for actionable short-horizon tasks
- Configurable 0-365 day focus horizon, default 7 days
- Buckets for overdue, today, upcoming, and undated priority work
- Priority-aware sorting
- New 7-day Focus command

## Retained
All v2.9 and earlier notes, search, knowledge, tasks, project dashboard, calendar, task board, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault and local-first privacy features.
