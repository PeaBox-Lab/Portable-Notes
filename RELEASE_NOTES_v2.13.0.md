# Portable Notes 2.23.0: Project Health

This cumulative release adds project-level health summaries derived from Markdown tasks.

## New
- `/api/task-projects` project-health endpoint
- Per-project completion percentage
- Open, completed, overdue, and high-priority counts
- Next open due date per project
- Risk-oriented project sorting
- New Project Health command

## Retained
All v2.12 and earlier notes, FTS search, knowledge tools, task intelligence, dashboards, calendar, board, focus, weekly review, productivity stats, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault and local-first privacy features.
