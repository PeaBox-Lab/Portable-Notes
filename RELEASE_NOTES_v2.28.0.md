# Portable Notes 2.28.0: Metadata Quality

This cumulative release adds task metadata governance and diagnostics while retaining all earlier functionality.

## New
- `/api/task-quality` with optional project filtering
- Task-quality score from 0-100
- Diagnostics for missing task IDs, due dates, baselines and estimates
- Duplicate task-ID detection
- Unresolved dependency detection
- Project-level quality percentage and clean-task counts
- New Metadata Quality command

## Retained
All v2.27 and earlier note, search, knowledge, task/project/milestone, dependency, critical-path, risk, workload, capacity, burndown, forecast, schedule, slippage, baseline-health, history, attachment, export, template, daily-note and privacy functionality remains.
