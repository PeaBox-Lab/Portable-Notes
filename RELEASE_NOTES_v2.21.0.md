# Portable Notes 2.29.0: Workload Planning

This cumulative release adds effort-aware workload planning while retaining all earlier capabilities.

## New
- Task effort metadata with `estimate: 2h` or `est: 2h`
- `/api/task-workload` with optional project filtering
- Estimated hours, unestimated work, overdue and next-7-day counts
- Deterministic load score for comparing project workload
- New Workload command

## Retained
All v2.20 and earlier notes, search, knowledge, task/project/milestone workflows, dependencies, critical-path analysis, Risk Radar, history, attachments, export, templates, daily notes, custom vault and privacy functionality remains.
