# Portable Notes 2.17.0: Milestones

This cumulative release adds milestone tracking to Markdown tasks while retaining all earlier functionality.

## New
- Milestone metadata using `milestone: Name` or `#milestone/Name`
- `/api/task-milestones` with optional project filtering
- Per-milestone total/open/done/overdue counts
- Completion percentage and next open due date
- New Milestones command

## Retained
All v2.15 and earlier notes, search, knowledge tools, task intelligence, dashboards, calendar, board, focus, weekly review, productivity stats, project health/workspace/timeline, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault and privacy features.
