# Portable Notes 2.17.0: Project Dashboard

A cumulative release adding vault-wide task and project rollups while retaining every v2.6 capability.

## New
- `/api/task-dashboard` project/task rollup
- Total, open, completed, and overdue task counts
- Per-project open, completed, overdue, and high-priority counts
- New Task & project dashboard command-palette action
- Markdown remains the source of truth; dashboard values are derived on demand

## Retained
All v2.6 and earlier notes, search, task intelligence, saved searches, wiki links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault, and privacy capabilities.
