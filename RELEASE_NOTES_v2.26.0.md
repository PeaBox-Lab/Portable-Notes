# Portable Notes 2.27.0: Schedule Slippage

This cumulative release adds baseline-vs-current due-date tracking while retaining all earlier functionality.

## New
- Baseline dates using `baseline: YYYY-MM-DD` or `base: YYYY-MM-DD`
- `/api/task-slippage` with optional project filtering
- Slipped, Ahead and On Baseline task classification
- Slip-day calculation per task
- Project maximum and average schedule slippage rollups
- New Schedule Slippage command

## Retained
All v2.25 and earlier note, search, knowledge, task/project/milestone, dependency, critical-path, risk, workload, capacity, burndown, forecast, schedule, history, attachment, export, template, daily-note and privacy functionality remains.
