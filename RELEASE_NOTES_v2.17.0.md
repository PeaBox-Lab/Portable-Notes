# Portable Notes 2.19.0: Milestone Board

This cumulative release turns milestone-tagged Markdown tasks into an execution board while retaining earlier functionality.

## New
- `/api/task-milestone-board` with optional project and milestone filters
- Overdue, Active and Done milestone lanes
- Per-milestone completion/open/overdue summaries
- Priority-aware task ordering
- New Milestone Board command

## Retained
All v2.16 and earlier notes, search, knowledge tools, task intelligence, dashboards, calendar, task board, focus, weekly review, productivity stats, project health/workspace/timeline, milestone tracking, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault and privacy features.
