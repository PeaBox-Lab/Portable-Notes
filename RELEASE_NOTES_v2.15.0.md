# Portable Notes 2.23.0: Project Timeline

This cumulative release adds chronological project planning while retaining all earlier functionality.

## New
- `/api/task-timeline` for chronological dated-task views
- Optional project filtering
- Monthly rollups with total, open, and completed counts
- Priority-aware ordering within dates
- New Project Timeline command

## Retained
All v2.14 and earlier notes, search, knowledge tools, task intelligence, dashboards, calendar, board, focus, weekly review, productivity stats, project health/workspace, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom vault and privacy features.
