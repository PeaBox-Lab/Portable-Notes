# Portable Notes 2.27.0: Burndown Planning

This cumulative release adds project burndown forecasting while preserving all prior capabilities.

## New
- `/api/task-burndown` with 1-90 day horizon
- Optional project filtering
- Total open estimated effort
- Ideal remaining-effort trajectory
- Scheduled remaining effort based on Markdown due dates
- One-hour default for open tasks without estimates
- New Burndown command

## Retained
All v2.22 and earlier note, search, knowledge, task/project/milestone, dependency, critical-path, risk, workload, capacity, history, attachment, export, template, daily-note and privacy functionality remains.
