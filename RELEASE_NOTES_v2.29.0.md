# Portable Notes 2.29.0: Execution Readiness

This cumulative release turns metadata and dependency signals into an execution-readiness view while retaining all earlier functionality.

## New
- `/api/task-readiness` with optional project filtering
- Deterministic readiness score for every open task
- Ready, Attention, and Blocked states
- Readiness blockers covering incomplete metadata, unresolved/waiting dependencies, duplicate IDs, and overdue work
- Project-level readiness percentage and state counts
- New Execution Readiness command

## Retained
All v2.28 and earlier note, search, knowledge, task/project/milestone, dependency, critical-path, risk, workload, capacity, burndown, forecast, schedule, slippage, baseline-health, metadata-quality, history, attachment, export, template, daily-note and privacy functionality remains.
