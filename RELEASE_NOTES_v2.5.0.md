# Portable Notes 2.5.0: Tasks and Projects

Portable Notes 2.5.0 begins the Tasks and Projects roadmap while retaining all 2.4 capabilities.

## New
- Global Markdown task aggregation across the vault
- Open/completed task filtering through `/api/tasks`
- Due-date recognition using `due: YYYY-MM-DD` or `📅 YYYY-MM-DD`
- Global open-task view from the command palette

## Retained
All 2.4 Markdown vault, FTS search, saved search, unlinked mention, duplicate detection, tabs, history, attachment, wiki-link, backlink, export, trash, template, daily-note, and privacy functionality remains.
