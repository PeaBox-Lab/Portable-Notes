# Portable Notes 2.21.0: Task Calendar

This cumulative release adds a calendar/agenda layer to Markdown tasks while retaining v2.7 and earlier features.

## New
- `/api/task-calendar` due-date agenda
- Optional `start` and `end` ISO-date filtering
- Chronological task ordering with completion and priority awareness
- Project, priority, note, path, and line context in calendar results
- New Task calendar command-palette action

## Retained
All prior Markdown vault, search, saved-search, knowledge, task intelligence, task/project dashboard, links/backlinks, tabs, history, attachments, export, trash, templates, daily notes, custom-vault and privacy functionality.
