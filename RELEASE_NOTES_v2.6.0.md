# Portable Notes 2.6.0: Task Intelligence

This cumulative release advances the task layer introduced in 2.5 without removing earlier functionality.

## New
- Task priorities: `priority: high|medium|low` or `!high`, `!medium`, `!low`
- Project metadata: `project: Name` or `#project/Name`
- Automatic overdue detection
- Project and priority filters on `/api/tasks`
- Useful task sorting by completion, overdue state, due date, priority, and note
- Command-palette views for overdue and high-priority tasks

## Retained
All v2.5 and earlier Markdown vault, task aggregation, search, saved search, link/backlink, history, attachments, export, trash, template, daily-note, and privacy capabilities remain.
