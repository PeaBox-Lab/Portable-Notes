
# Portable Notes 2.2.0: Writing Experience

This release builds directly on 2.1.0 without removing features.

## New
- Persistent multi-note tabs
- Find and replace (`Ctrl+F`)
- Automatic local note snapshots before saves
- Restore previous note content through the command palette

## Retained
All 2.1.0 Markdown vault, folder, tag, wiki-link, backlink, daily-note, template, search/index, export, trash, theme, preview and privacy features remain.
