
# Portable Notes 2.1.0: Markdown Vault Foundation

Portable Notes 2.1.0 makes Markdown files the source of truth while retaining a fast, replaceable SQLite index. Notes remain readable in Obsidian, Notepad++, VS Code, and any standard text editor.

## Highlights
- Local Markdown vault with nested folders
- Wiki links, backlinks, tags, favorites, and pinned notes
- Daily notes, templates, command palette, search, preview, and autosave
- External modification detection and rename-safe link updates
- ZIP vault export and recoverable internal trash

## Install
Download and extract the ZIP, then run `start.bat` on Windows or `python app.py`. Python 3.9 or newer is required.
