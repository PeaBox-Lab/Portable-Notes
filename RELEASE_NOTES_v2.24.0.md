# Portable Notes 2.28.0: Delivery Forecast

This cumulative release adds capacity-based project delivery forecasting while retaining all prior capabilities.

## New
- `/api/task-forecast` with configurable 1-168 hour weekly capacity
- Optional project filtering
- Remaining effort and weeks-needed forecast
- Capacity-derived finish date
- Latest due-date comparison
- On Track / At Risk schedule classification
- New Delivery Forecast command

## Retained
All v2.23 and earlier note, search, knowledge, task/project/milestone, dependency, critical-path, risk, workload, capacity, burndown, history, attachment, export, template, daily-note and privacy functionality remains.
